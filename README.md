# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数与异常处理看板

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

- 新增巡检记录：房间编号、洁净等级、0.5μm 粒子数、温湿度、压差
- 系统按 ISO 14644-1 各等级 0.5μm 粒子上限自动判定：≤ 上限为正常，≥ 上限 80% 为关注，超限为异常（等级不可手填）
- 处置流转：待处理 → 处理中 → 已关闭；仅厂务工程师可推进，关闭必须填写处理说明，未填则保留待处理
- 正常记录自动归档；关注/异常记录进入待处理
- 顶部计数（总数/关注/异常/待处理）与等级、判定、状态筛选跟随台账实时变化
- 台账与角色通过 localStorage 持久化，重新打开页面可看到处置进度
