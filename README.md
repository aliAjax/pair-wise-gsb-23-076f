# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数自动定级与异常处置闭环台账。

## 技术栈

React + Vite + TypeScript + CSS（数据保存在浏览器 localStorage，无需后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

- **新增巡检记录**：房间编号、洁净等级（ISO 5 / ISO 6 / ISO 7 / 黄光区）、
  0.5μm 粒子数、温度、湿度、压差；提交时校验必填项与取值范围。
- **系统自动定级**（级别由系统给出，不可手填），按各等级 0.5μm 粒子上限判定：
  - 正常：粒子数 ≤ 上限的 80%
  - 关注：上限的 80%–100%
  - 异常：超过上限
  - 上限采用 ISO 14644-1（粒/m³）：ISO 5 = 3,520；ISO 6 = 35,200；
    ISO 7 = 352,000；黄光区按 ISO 7 管控。
  - 录入时实时显示占上限百分比与预判定级。
- **处置流程与角色权限**（右上角切换角色，选择也会记住）：
  - 巡检员：可新增记录；不能推进或关闭。
  - 厂务工程师：只有该角色能把 **待处理 → 处理中**；处理中记录必须填写
    **处理说明** 才能关闭，没写则保留当前进度并给出提示。
  - 班组长：只读查看。
  - 判定为正常的记录直接留档关闭；关注 / 异常进入待处理。
- **台账与计数**：顶部粒子异常 / 关注 / 待处理 / 处理中计数、各筛选维度上的
  计数都随记录实时变化；支持房间搜索和等级、级别、进度筛选。
- **浏览器持久化**：记录与当前角色保存在 localStorage，重新打开页面仍能看到
  历史记录与处置进度（登记 / 推进 / 关闭的时间与操作人、处理说明）。
